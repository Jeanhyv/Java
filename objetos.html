Objetos, Propiedades y Métodos

🏗️ ¿Qué es un objeto?

Un objeto es una colección de datos y funciones agrupadas bajo un mismo nombre. Los datos se almacenan en propiedades y las funciones dentro del objeto se llaman métodos. 


        let persona = {
          nombre: "Jean",
          edad: 21,
          saludar: function() {
            alert("Hola, soy " + this.nombre);
          }
        };

🧩 Ejemplos de objetos, propiedades y métodos

1️⃣ Crear un objeto simple

Un objeto puede tener varias propiedades con diferentes tipos de datos.


            let coche = {
              marca: "Toyota",
              modelo: "Corolla",
              año: 2020
            };

2️⃣ Acceder a propiedades

Podemos acceder a las propiedades usando punto (.) o corchetes [].


            alert(coche.marca);
            alert(coche["modelo"]);

3️⃣ Modificar propiedades

Podemos cambiar el valor de una propiedad o agregar nuevas.


            coche.color = "Rojo";
            coche.año = 2023;

4️⃣ Agregar métodos

Los métodos son funciones dentro del objeto que pueden usar this.


            let persona = {
              nombre: "Jean",
              saludar: function() {
                alert("Hola, soy " + this.nombre);
              }
            };
            persona.saludar();

5️⃣ Objetos anidados

Un objeto puede contener otros objetos dentro.


            let estudiante = {
              nombre: "Héctor",
              direccion: {
                ciudad: "México",
                cp: 12345
              }
            };
            alert(estudiante.direccion.ciudad);

6️⃣ Recorrer propiedades con for...in

Podemos recorrer todas las propiedades de un objeto usando un bucle.


            for (let propiedad in coche) {
              console.log(propiedad + ": " + coche[propiedad]);
            }

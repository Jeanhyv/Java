¿Qué es JavaScript?

El lenguaje que da vida e interactividad a las páginas web.

📘 Definición

JavaScript es un lenguaje de programación interpretado que permite agregar interactividad y dinamismo a las páginas web. Es ejecutado por el navegador y trabaja junto con HTML y CSS para crear experiencias modernas en internet.

Entrada y Salida de Datos

📥 ¿Qué es la entrada de datos?

La entrada de datos consiste en obtener información desde el usuario o desde alguna fuente externa. En JavaScript, los métodos más comunes son:

  • prompt() → Muestra un cuadro de texto para que el usuario ingrese información.
  • confirm() → Muestra una pregunta con opciones Aceptar/Cancelar.
  • HTML inputs → Permiten ingresar datos directamente en la página.

📤 ¿Qué es la salida de datos?

La salida de datos consiste en mostrar información al usuario. Los métodos más usados son:

  • alert() → Muestra un mensaje emergente.
  • console.log() → Muestra información en la consola del navegador (útil para pruebas).
  • document.write() → Escribe directamente en el documento HTML.

💻 Ejemplos prácticos

1️⃣ Entrada con prompt()

Pide al usuario su nombre y lo muestra con un mensaje de bienvenida.


let nombre = prompt("¿Cómo te llamas?");
alert("Hola " + nombre + "!");

2️⃣ Confirmación con confirm()

Usa confirm para hacer una pregunta con respuesta de Sí o No.


let continuar = confirm("¿Deseas continuar?");
alert("Tu respuesta fue: " + continuar);

3️⃣ Mostrar en consola

Muestra información en la consola (usa console.log()).


console.log("Este es un mensaje en la consola");

4️⃣ Escribir en el documento

Usa document.write() para mostrar texto directamente en la página.


document.write("Hola desde JavaScript!");

5️⃣ Entrada desde HTML

Obtiene texto de un campo y lo muestra en pantalla sin usar ventanas emergentes.

Conversión de Tipos de Expresiones

📘 ¿Qué es la conversión de tipos?

La conversión de tipos ocurre cuando un valor cambia de un tipo de dato a otro. Esto puede hacerse de forma explícita (intencional por el programador) o implícita (automáticamente por el lenguaje).

🔄 Conversión Explícita

1️⃣ Convertir a número

Podemos usar Number() para transformar texto en número.

let num = Number("25");

2️⃣ Convertir a cadena

Usando String() o concatenación.

let texto = String(123);

3️⃣ Convertir a booleano

Con Boolean() puedes convertir valores a verdadero o falso.

Boolean(0) → false  
            Boolean("hola") → true

⚙️ Conversión Implícita (Coerción de tipos)

💡 Suma entre cadena y número

JavaScript convierte el número a texto cuando hay una cadena.

"5" + 2 → "52"

🧮 Resta entre cadena y número

En este caso, JavaScript intenta convertir la cadena a número.

"10" - 5 → 5

⚖️ Comparación con ==

El operador == convierte tipos antes de comparar.

0 == false → true  
            "5" == 5 → true

Funciones

🧩 ¿Qué es una función?

Una función es un bloque de código que realiza una tarea específica. Se puede ejecutar varias veces sin tener que escribir el mismo código de nuevo.

En JavaScript, las funciones pueden:

  • Recibir datos (parámetros).
  • Procesar esos datos.
  • Devolver un resultado (valor de retorno).

🧮 Declaración de funciones

1️⃣ Función simple

Una función básica que muestra un mensaje.


function saludar() {
  alert("¡Hola desde una función!");
}

2️⃣ Función con parámetros

Las funciones pueden recibir datos externos.


function sumar(a, b) {
  return a + b;
}

3️⃣ Función con retorno

Una función puede devolver un valor con return.


function multiplicar(x, y) {
  return x * y;
}
let resultado = multiplicar(4, 5);
alert("El resultado es: " + resultado);

4️⃣ Función anónima

Se puede asignar una función a una variable.


const saludarAnonimo = function() {
  alert("Hola desde una función anónima");
};

5️⃣ Función flecha (arrow function)

Una forma más corta de escribir funciones en JavaScript.


const saludarFlecha = (nombre) => {
  return "Hola " + nombre + "!";
};
alert(saludarFlecha("Jean"));

6️⃣ Función que llama a otra función

Las funciones pueden usar otras funciones para realizar tareas más complejas.


function cuadrado(num) {
  return num * num;
}
function mostrarResultado() {
  alert("El cuadrado de 4 es " + cuadrado(4));
}

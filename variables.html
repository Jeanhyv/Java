Variables

📘 ¿Qué es una variable?

Una variable es un contenedor que guarda información o valores que pueden cambiar durante la ejecución de un programa. En JavaScript se pueden declarar con var, let o const.

🧩 Tipos de declaración de variables

1️⃣ var

var es la forma más antigua de declarar variables. Tiene alcance de función y permite redeclaraciones. 

var nombre = "Jean";

2️⃣ let

let tiene alcance de bloque y no puede redeclararse dentro del mismo ámbito. 

let edad = 21;

3️⃣ const

const se usa para valores que no cambian. Una vez asignado, no puede modificarse. 

const pais = "México";

⚙️ Comportamientos especiales

💡 Hoisting con var

Las variables declaradas con var se “elevan” (hoisting) antes de su ejecución.


console.log(x); // undefined
var x = 5;

🔒 let y const dentro de bloques

Las variables declaradas con let y const solo existen dentro del bloque donde fueron declaradas. 


{
  let a = 10;
  const b = 20;
}
console.log(a); // Error

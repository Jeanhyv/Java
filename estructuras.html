Estructuras de Control

🧭 ¿Qué son las estructuras de control?

Las estructuras de control permiten que un programa tome decisiones o repita tareas según ciertas condiciones. Son fundamentales para definir la lógica del flujo del programa.

⚖️ Estructuras condicionales

Permiten ejecutar bloques de código dependiendo del resultado de una condición (verdadero o falso).

1️⃣ if / else

Evalúa una condición y ejecuta un bloque de código si se cumple.


            let edad = 18;
            if (edad >= 18) {
              alert("Eres mayor de edad");
            } else {
              alert("Eres menor de edad");
            }

2️⃣ if / else if / else

Permite verificar múltiples condiciones.


            let nota = 85;
            if (nota >= 90) {
              alert("Excelente");
            } else if (nota >= 70) {
              alert("Aprobado");
            } else {
              alert("Reprobado");
            }

3️⃣ switch

Evalúa una expresión y ejecuta un bloque según el caso que coincida.


            let dia = "Lunes";
            switch(dia) {
              case "Lunes":
                alert("Inicio de semana");
                break;
              case "Viernes":
                alert("Fin de semana");
                break;
              default:
                alert("Día normal");
            }

🔁 Bucles o ciclos

Los bucles permiten repetir instrucciones mientras se cumpla una condición. Son muy útiles para recorrer listas o realizar tareas repetitivas.

1️⃣ for

Repite un bloque de código un número determinado de veces.


            for (let i = 1; i <= 5; i++) {
              console.log("Número: " + i);
            }

2️⃣ while

Repite un bloque de código mientras la condición sea verdadera.


            let i = 1;
            while (i <= 3) {
              console.log("Iteración: " + i);
              i++;
            }

3️⃣ do...while

Ejecuta el bloque de código al menos una vez, luego evalúa la condición.


let x = 1;
do {
  console.log("Número: " + x);
  x++;
} while (x <= 3);

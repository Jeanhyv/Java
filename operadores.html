Operadores y Expresiones

📘 ¿Qué son los operadores y expresiones?

Una expresión es cualquier combinación de valores, variables y operadores que produce un resultado. Los operadores son los símbolos que permiten realizar operaciones sobre esos valores.

🧮 Tipos de Operadores

1️⃣ Aritméticos

Permiten realizar operaciones matemáticas básicas.

+, -, *, /, %, ++, --

2️⃣ De Asignación

Sirven para asignar valores a variables.

=, +=, -=, *=, /=, %=

3️⃣ Comparación

Comparan dos valores y devuelven un resultado booleano.

==, ===, !=, !==, >, <, >=, <=

4️⃣ Lógicos

Permiten combinar o negar condiciones.

&& (AND), || (OR), ! (NOT)

5️⃣ De Concatenación

Usados para unir cadenas de texto.

"Hola " + "Mundo"

⚙️ Operadores con Diferentes Semánticas (Funciones)

🧠 Operador +

Puede sumar números o concatenar cadenas.


            5 + 10 → 15
            "Hola" + " Mundo" → "Hola Mundo"

🧮 Operador == vs ===

== compara solo valores, === compara tipo y valor.


            5 == "5" → true
            5 === "5" → false

🔁 Operador ternario (?:)

Sirve para evaluar una condición de forma compacta.


            let edad = 18;
            let mensaje = (edad >= 18) ? "Mayor de edad" : "Menor de edad";
